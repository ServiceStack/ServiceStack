# Security & Hardening Changes: ServiceStack.Skia

## Overview
This document summarizes the native memory leak remediations, crash prevention, input validation, and API robustness improvements implemented in `ServiceStack.Skia`.

---

### 1. Elimination of Unmanaged Native Memory Leaks in Image Pipeline
- **Severity**: High / Memory Leak & Denial of Service
- **Issue**:
  - In `ResizeToPng`, intermediate bitmaps generated by `img.Resize(...)` and `Crop(...)` were never deterministically disposed when resizing images. Because `SKBitmap` allocates native unmanaged C++ memory inside the underlying Skia engine, repeated image operations caused memory bloat and native memory exhaustion under high volume.
  - Calling `img.Encode(...).AsStream()` directly retained native `SKData` references within unmanaged stream wrappers instead of safely transferring bytes to managed memory.
- **Remediation**:
  - Implemented deterministic disposal tracking: intermediate bitmaps generated during resize and crop stages are guaranteed to be disposed in a `finally` block.
  - Copied encoded PNG bytes into a managed seekable stream via ServiceStack's pooled `MemoryStreamFactory.GetStream()`, immediately releasing the unmanaged `SKImage` and `SKData` objects.
  - Ensured returned stream is seekable with `Position = 0`.

---

### 2. Null Pointer & Corrupt Image Stream Crash Prevention
- **Severity**: Medium / Crash Resilience
- **Issue**:
  - Passing an empty stream, non-image stream, or corrupted file caused `SKBitmap.Decode(stream)` to return `null`.
  - `ResizeToPng(null, ...)` immediately dereferenced `img.Width`, crashing with an unhandled `NullReferenceException`.
  - Streams whose `Position > 0` (e.g., from prior reads or uploads) failed to decode because they were not rewound.
- **Remediation**:
  - Added stream null guard (`ArgumentNullException`).
  - Rewound seekable streams (`if (stream.CanSeek && stream.Position != 0) stream.Position = 0;`).
  - Validated that `SKBitmap.Decode(stream)` returned a valid bitmap; threw descriptive `ArgumentException("Failed to decode image from stream.", nameof(stream))` instead of throwing `NullReferenceException`.

---

### 3. Dimension Bounds Checking & Zero-Division Prevention
- **Severity**: Medium / Crash Resilience & Arithmetic Safety
- **Issue**:
  - Passing non-positive dimensions (`newWidth <= 0` or `newHeight <= 0`) led to non-positive aspect ratios and negative/zero Skia dimensions, throwing native exceptions.
  - If an image had zero width or height, calculating `ratioX = (double)newWidth / img.Width` produced `Infinity` or `NaN`, which truncated to integer min values and failed.
- **Remediation**:
  - Added strict parameter checks on `newWidth` and `newHeight` throwing `ArgumentOutOfRangeException`.
  - Added validation for `img.Width > 0 && img.Height > 0` throwing `ArgumentException`.
  - Used `Math.Max(1, (int)Math.Round(...))` to guarantee valid dimension calculations.

---

### 4. Prevention of Destructive Disposal in `Crop`
- **Severity**: Medium / API Correctness & Object Invalidation
- **Issue**:
  - `public static SKBitmap Crop(SKBitmap img, int newWidth, int newHeight)` executed `img.Dispose()` on the caller's input bitmap at the end of the method.
  - Any external caller using `Crop(bitmap, ...)` had their original bitmap unexpectedly disposed, leading to subsequent `ObjectDisposedException` or invalid memory access.
- **Remediation**:
  - Removed `img.Dispose()` from `Crop`. The caller owns the lifecycle of the input bitmap.
  - Disposed intermediate bitmaps safely inside `ResizeToPng` without mutating or disposing the caller's original image.

---

### 5. Multi-Targeting & Modernization
- **Severity**: Quality / Compatibility
- **Issue**:
  - `ServiceStack.Skia.csproj` targeted only `net6.0;net8.0`, missing modern `net10.0`.
  - Contained a typo in `<PackageDescription>`: `"Imagigng"`.
- **Remediation**:
  - Added `net10.0` target framework to `ServiceStack.Skia.csproj` with appropriate conditional constants (`NET10_0_OR_GREATER`).
  - Corrected spelling to `"Imaging"`.
  - Added `SkiaImageExtensions` extension methods (`img.ResizeToPng(...)`, `img.Crop(...)`) for enhanced ergonomics matching `ServiceStack.Desktop`.
